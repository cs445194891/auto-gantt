# auto-gantt｜单文件离线甘特图生成器

一个无需后端、无需联网的单页面工具：导入 Excel/CSV 模板或直接在页面里填写任务，即时生成甘特图；支持三种视觉风格（各 4 套配色组合）、两套渲染引擎、时间轴缩放（日 / 周 / 月 / 季自动分级）、可调行高与任务列宽、显示开关（今日红线 / 百分比进度 / 起止日期列）、分组内拖放排序，并可导出为多种格式。

**本仓库是源码仓库**：构建产物（`gantt.html` 与 `甘特图模板.xlsx`）不纳入版本控制，需本地构建生成；也可直接从 [Releases](https://github.com/cs445194891/auto-gantt/releases) 下载预构建成品，无需构建。

> ⚠️ **不要直接双击打开 `build/gantt.src.html`**：它是带占位符的源码，两个依赖库尚未内嵌，Mermaid 引擎与 Excel 导入 / 导出 `.xlsx` 会不可用（页面顶部会显示明确提示）。请打开构建生成的根目录 `gantt.html`，或下载 Release 中的成品。

## 快速开始

```bash
npm install
npm run build
```

构建完成后得到：

| 文件 | 说明 |
| --- | --- |
| `gantt.html` | 约 4.1 MB 的自包含单文件，内嵌 SheetJS 与 Mermaid，**双击即可离线使用** |
| `甘特图模板.xlsx` | 6 列标准模板（「任务数据」+「填写说明」两个工作表） |

也可以直接执行 `node build/build.js`。网页本身还提供「下载 Excel 模板」按钮，因此即使不构建，只要拿到 `gantt.html` 也能生成模板。

### 依赖从哪来

`build/build.js` 按以下顺序查找两个 UMD 构建：

1. `build/vendor/xlsx.full.min.js`、`build/vendor/mermaid.min.js`（离线缓存，不入库）；
2. `node_modules/xlsx/dist/xlsx.full.min.js`、`node_modules/mermaid/dist/mermaid.min.js`（`npm install` 得到）。

两者都缺时会报错并给出指引。已核实：npm 包 `xlsx@0.18.5` 与 `mermaid@10.9.3` 内的这两个 `dist/*.min.js`，与本项目原始 `build/vendor/` 文件的 SHA-256 完全一致，因此两种路径生成的 `gantt.html` 字节一致。

## 使用方法

1. 打开构建出的 `gantt.html`；
2. 导入 `.xlsx / .xls / .csv`（或页面导出的 `.json`），也可直接编辑页面下方的数据表格；
3. 选择风格（正式 / 简约 / 花哨）与渲染引擎（SVG 精细 / Mermaid）；
4. 用「时间轴缩放」滑块调整横向密度：刻度随缩放自动由 日 → 周 → 月 → 季 分级，长周期项目可压到很短；旁边的「粒度」下拉可手动锁定单位。另有「行高」滑块（20–64 px）、「任务列宽」（默认按最长任务 / 分组名自动取最窄，取消「自动最窄」后可用滑块手动调 90–320 px）与「显示」区三个开关（今日红线 / 百分比进度 / 每条起止日期）；
   - **关闭「百分比进度」＝不表达进度**：所有任务条统一按已完成色实心显示，百分比文字隐藏；SVG 与 Mermaid 两个引擎同口径。
   - **开启「每条起止日期」**：在左侧「任务 / 分组」列右边新增一列，逐行显示 `YY/MM/DD-YY/MM/DD`（里程碑为单点，只显示当天）；关闭时整列消失，条形后面不再堆日期文字。Mermaid 引擎无表格列，只能以任务名后缀近似表达。
5. 展开「外观设置」：每种风格有 4 套配色组合，切换只覆盖 7 项颜色、不重置字号；另有 10 项字号与颜色可单独调整，三种风格各自独立保存并随 JSON 导入导出；
6. 在下方表格中直接编辑；拖动行首 ⠿ 手柄可在**同一分组内**调整顺序，跨分组不可拖放；
7. 导出所需格式。

### 模板字段口径（6 列，顺序如下）

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 分组 | 否 | 首列；同名分组自动归入同一段，按首次出现顺序排列；表格内可在同组拖放排序 |
| 任务名称 | 是 | 文本，建议不超过 20 字 |
| 开始日期 | 是 | `YYYY-MM-DD`；也兼容 `2026/11/9`、`2026年11月9日`、Excel 日期序列号 |
| 结束日期 | 是 | 含结束当日；里程碑行可留空 |
| 进度 % | 否 | 0–100 的整数，不按小数比例解释；留空按 0 |
| 里程碑 | 否 | `是 / Y / 1 / ✓` 均视为里程碑，显示为菱形单点 |

v0.1.0 的 7 列模板（含「负责人」列）仍可导入，该列会被自动忽略，其余列按表头名定位；**不带表头的 CSV** 按上表 6 列顺序解析，旧版无表头 7 列 CSV 需补表头或删去「负责人」列。

### 时间轴缩放口径

滑块（1–100）对数映射到「每日等效像素」0.3–44 px/日；任务条始终按真实日期线性定位，粒度只改变网格与刻度标签的单位。默认自动分级：`≥6` 为日、`≥1.5` 为周、`≥0.5` 为月、更小为季；网格与标签按像素密度自动抽稀。上层色带在日 / 周粒度按月份切块、月 / 季粒度按年份切块。缩放档位、粒度锁定、行高、任务列宽（含自动 / 手动模式）、三个显示开关与配色选择都会写入导出的 JSON，导入时一并恢复（也兼容 v0.1.0 的 `dayWidth` 字段；旧版 JSON 没有列宽字段时按「自动最窄」处理）。

### 导出格式

PNG（2 倍分辨率）、SVG、PDF（调起浏览器打印对话框，横向另存为 PDF）、CSV、XLSX、JSON、Mermaid `.mmd` 代码。

## 已知边界

- 时间轴缩放、行高、任务列宽与显示开关以 **SVG 精细引擎** 为准。Mermaid 引擎下：刻度粒度近似映射（`axisFormat` / `tickInterval`，季粒度降级为 `1month`）、今日线开关与「关闭百分比进度＝全部已完成色」生效；行高、任务列宽不生效；起止日期只能以任务名后缀表达，没有左侧日期列。
- Mermaid gantt 语法没有原生「进度百分比」与任务级配色，该引擎用 `done / active` 状态标签 + 任务名后缀近似表达，风格差异小于 SVG 引擎。
- 若页面提示「Mermaid 库未内嵌」或「Excel 库未内嵌」，说明打开的是 `build/gantt.src.html` 源码文件（或成品文件被截断）；按页面横幅提示构建 / 重新下载即可，不要直接编辑源码文件来试功能。
- 拖放排序仅限**同一分组的连续区块**：若同分组任务被其他分组的行隔开，跨区块拖放会被拒绝并提示；先修改「分组」列使同组行连续即可。
- PDF 不是直接生成 `.pdf` 文件，而是打印对话框另存。
- `gantt.html` 的体积主要来自内嵌的两个第三方库，不是自研代码冗余。
- 本工具不实现任务依赖、关键路径、资源平衡、挣值等项目管理逻辑。
